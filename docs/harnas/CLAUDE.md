# Harness — Rails + Hotwire (+ Hotwire Native Android)

A fixed set of rules for Job's own Rails apps (notesk, habittrack, uitgaven,
lookout, gvexcelsior, portfolio, mealist, and new ones). Read every rule file
below and follow them strictly. The Laravel/Code14 projects use a different
harness; this one is not for them.

## Language policy

- All rules are written in English. The rule files stay English.
- The AI communicates with the developer in Dutch and explains the rules in
  Dutch when asked. The rules themselves are never rewritten in Dutch.
- Throughout these rules, **"the developer"** means the person the AI is working
  with. **"The user"** is reserved for the user of the application being built.

## Precedence

1. The project's own `AGENTS.md` / `CLAUDE.md` wins over this harness. Where it
   deviates on purpose, that is fine; where it is silent, this harness applies.
2. A project may have a project file next to this harness
   (`~/Desktop/harness/<project>.md`) with facts and open points for that app.
3. A rule marked ⚠️ in a project file is an open point: ask, never fill in.
